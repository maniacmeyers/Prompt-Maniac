# Deploy to Your Own Netlify Account

## Quick Deploy via Netlify Dashboard (Easiest)

1. **Create a GitHub repository** (if you haven't already)
   - Go to https://github.com/new
   - Create a new repository
   - Don't initialize with README (we have code already)

2. **Push your code to GitHub**
   ```bash
   cd prompt-maniac
   git init
   git add .
   git commit -m "Initial commit - Prompt Maniac"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   git push -u origin main
   ```

3. **Import to Netlify**
   - Go to https://app.netlify.com
   - Click "Add new site" → "Import an existing project"
   - Choose "Deploy with GitHub"
   - Authorize Netlify to access your GitHub
   - Select your repository
   
4. **Configure Build Settings**
   - Build command: `bun run build` or `npm run build`
   - Publish directory: `.next`
   - Click "Show advanced" → "New variable"
   
5. **Add Environment Variables**
   
   Add these three variables:
   
   **DATABASE_URL**:
   ```
   postgresql://postgres.kqbryfsfjxlinwgolnpo:[YOUR-PASSWORD]@aws-1-us-east-1.pooler.supabase.com:6543/postgres?pgbouncer=true&connection_limit=1
   ```
   
   **DIRECT_URL**:
   ```
   postgresql://postgres.kqbryfsfjxlinwgolnpo:[YOUR-PASSWORD]@aws-1-us-east-1.pooler.supabase.com:5432/postgres
   ```
   
   **OPENAI_API_KEY**:
   ```
   sk-proj-your-api-key-here
   ```

6. **Click "Deploy site"**
   - Wait for build to complete (~2-3 minutes)
   - Your site will be live at a Netlify URL

7. **Run Migrations**
   
   After deployment, you need to run database migrations:
   
   ```bash
   # Install Netlify CLI
   npm install -g netlify-cli
   
   # Login
   netlify login
   
   # Link your site
   cd prompt-maniac
   netlify link
   
   # Run migrations
   bunx prisma migrate deploy
   ```

8. **Seed Templates**
   ```bash
   curl -X POST https://YOUR-SITE.netlify.app/api/templates/seed
   ```

9. **Test Your Site**
   - Visit your Netlify URL
   - Create a project
   - Generate a prompt
   - Verify everything works!

## Alternative: Deploy via Netlify CLI

If you prefer command-line deployment:

```bash
# Install Netlify CLI
npm install -g netlify-cli

# Login to Netlify
netlify login

# Deploy from project directory
cd prompt-maniac
netlify deploy --prod

# Follow prompts to create new site or link existing
# Set build command: bun run build
# Set publish directory: .next

# Add environment variables
netlify env:set DATABASE_URL "postgresql://postgres.kqbryfsfjxlinwgolnpo:[YOUR-PASSWORD]@aws-1-us-east-1.pooler.supabase.com:6543/postgres?pgbouncer=true&connection_limit=1"
netlify env:set DIRECT_URL "postgresql://postgres.kqbryfsfjxlinwgolnpo:[YOUR-PASSWORD]@aws-1-us-east-1.pooler.supabase.com:5432/postgres"
netlify env:set OPENAI_API_KEY "sk-proj-your-api-key-here"

# Redeploy with environment variables
netlify deploy --prod

# Run migrations
bunx prisma migrate deploy

# Seed templates
curl -X POST https://YOUR-SITE.netlify.app/api/templates/seed
```
